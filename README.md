# csc458-extra-test-cases
Extra test cases for the 2026 Fall CSC458 assignments, feel free to add more if you find this!

## Usage
Copy the additional test Python file(s) into your assignment's test folder, and run the test cases as you normally would with `pytest` (they should show up with the same command that works with the pre-made test cases). If it's not showing you ALL test results (including passed ones), then ensure that you have the `-rA` flag at the end of your `pytest` command. Below is the full command to run from the root of the assignment's folder for reference since I know you'll forget it:

`python3 -m pytest -q -rA`
