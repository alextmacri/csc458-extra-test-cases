# csc458-extra-test-cases
Extra test cases for the 2026 Fall CSC458 assignments, feel free to add more if you find this!

## Usage
1. Copy the additional test Python file(s) into your assignment's test folder (the one that already has the pre-made test files in it).
2. Run the test cases as normal, from the root of the project folder with the `pytest` command.

For reference, here's the full command to run that also shows passed tests:

`python3 -m pytest -q -rA`

## Adding More Test Cases
If you want to add more test cases, I would recommend adding a new file just to keep things clean. If you think any existing test cases are incorrect, then whatever just change them it's small potatoes worst case scenario I'll just revert the changes if they're causing us grief. But I appreciate anyone else coming in here and improving the tests! :)
